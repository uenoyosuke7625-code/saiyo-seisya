# Revive Gym 北堀江 採用LP

トレーナー職（正社員1名）採用のランディングページ。

```
index.html    採用LP本体
thanks.html   エントリー送信後のサンクスページ
images/       写真素材を入れる場所
```

---

## 公開前にやること

### 1. 【要確認】を全部つぶす

`index.html` を開いて **「要確認」** で検索してください。
黄色いマーカーが引かれている箇所が、まだ確定していない項目です。

| 箇所 | 内容 |
|---|---|
| 募集要項｜応募資格 | 必須資格を明記（NSCA-CPT／柔道整復師／理学療法士 など） |
| 募集要項｜給与 | 昇給・賞与・インセンティブの有無 |
| 募集要項｜勤務時間 | 実際の営業時間 |
| 募集要項｜休日 | 週休2日制（シフト制）／年間休日108日 で確定してよいか |
| 募集要項｜待遇 | 交通費の上限 |
| 募集要項｜試用期間 | 有無・期間・条件 |
| 一日の流れ | 時間帯を実際の営業時間に合わせる |
| FAQ｜選考の流れ | 返信までの日数、面談回数 |
| VOICE（先輩インタビュー） | 桃子さんに実際に聞いて、回答を差し替える |
| フッター | 正式な住所 |

**インタビューの回答は「たたき台」です。** ご本人に確認せずそのまま公開しないでください。

### 2. 写真を入れる

`index.html` の中に、点線の枠で写真の入る位置を示してあります。

| 番号 | 内容 | 推奨サイズ |
|---|---|---|
| 写真① | ジム全景／マシンが並ぶ空間 | ✅ **配置済み**（`images/hero.jpg`） |
| 写真② | 桃子さんの指導風景（縦） | ⬜ 未配置（900×1200px 程度） |

写真を `images/` に置いて、該当箇所の `<div class="ph ...">...</div>` を
`<img src="images/ファイル名.jpg" alt="説明">` に置き換えてください。

> **写真の現像について**
> 既存サイトはブルー基調で少し冷たい印象なので、このLPでは
> **暖色寄り（露出やや高め・彩度控えめ）** に統一すると狙いどおりの空気になります。

### 3. Netlify で公開する

すでに Netlify のアカウントをお持ちなので、そのまま使えます。

1. このフォルダごと Netlify の「Drag and drop your project folder here」にドロップ
2. 公開完了（`◯◯◯.netlify.app` のURLが発行されます）

**エントリーフォームは Netlify Forms で動くように作ってあります。**
サーバーの用意は不要で、送信内容は Netlify の管理画面 → **Forms** に溜まります。

> 通知メールの設定：Netlify → Forms → Settings → Form notifications →
> 「Email notification」に受信したいメールアドレスを登録してください。
> **これを設定しないと応募に気づけません。必ずやってください。**

### 4. URLについて

現状は `noindex`（検索エンジンに載らない設定）にしてあります。
Instagram広告とSNSからの流入だけを想定しているためです。検索でも拾いたい場合は
`index.html` の `<meta name="robots" content="noindex">` の行を削除してください。

独自ドメインにする場合の推奨は **`recruit.revive-gym.jp`**。
本体サイトと同じドメイン配下になるので信頼性が上がります。
DNSの設定が必要なので、ホームページの発注先に依頼してください。

## デザインの考え方

既存サイト（revive-gym.jp）の骨格を継承しつつ、地の色だけを変えています。

**継承したもの**
- 明朝体の見出し（Shippori Mincho）
- 英字ラベル（`MESSAGE` `STORY` `ABOUT`…）を淡いブルーで小さく置く構成
- 大きな余白と中央揃えのリズム
- CTAボタンのブルー `#2E8BF2`

**変えたもの**
- 背景を純白 `#FFFFFF` → 生成り `#FCFAF7`
- 温かいベージュの帯 `#F5EFE7` を追加
- 本文書体に丸みのあるゴシック（Zen Kaku Gothic New）を採用

純白＋ブルーは清潔感がある反面やや冷たく見えるため、地の色に温度を持たせることで
「同じブランドだが、人の体温がある」状態をつくっています。

## 構成の意図

1. **HERO** — 本体サイトの「姿勢が変わる、人生が変わる」を受けたコピー
2. **MESSAGE** — 会員さまの実際の言葉で、この仕事のやりがいを提示
3. **STORY** — 代表の事故と回復。**このLP最大の差別化要素**
4. **ABOUT** — 東大式マシンという事業の独自性
5. **MEDIA** — 関西テレビ・ABC放送・朝日新聞。応募者が家族を説得できる材料
6. **WORK** — 仕事内容と一日の流れ
7. **VOICE** — 女性が働く場所としての安心感
8. **PERSON** — 求める人物像＋**正直にお伝えしたいこと**
9. **ENVIRONMENT / FAQ / REQUIREMENTS**
10. **ENTRY**

STORY を ABOUT より前に置いています。求人LPは条件ではなく共感で読まれるためです。

**「正直にお伝えしたいこと」を意図的に入れています。**
華やかな現場ではないことを先に書くことで、応募数はやや減りますが、
残った応募者の質と定着率が上がります。1名採用ではこちらが有利です。

## 表記についての注意

募集要項に「25〜30歳」「女性」と明記することは、
男女雇用機会均等法・労働施策総合推進法により原則できません。

このLPは **表記は中立に保ちつつ、デザイン・写真・文体・登場人物で
ターゲット層に届くよう設計** してあります。この方針は変えないでください。
