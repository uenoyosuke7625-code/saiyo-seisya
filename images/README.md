# images

採用LPで使う写真を置くフォルダ。

| ファイル名（推奨） | 内容 | 推奨サイズ |
|---|---|---|
| `hero.jpg` | ✅ 配置済み。Google Drive の `IMG_7308.jpg` を 1079×780 / 132KB に最適化 | — |
| `trainer.jpg` | ⬜ 未配置。桃子さんの指導風景（縦） | 900×1200px 程度 |

配置したら `index.html` の点線プレースホルダ（`<div class="ph ...">`）を
`<img src="images/hero.jpg" alt="Revive Gym 北堀江の店内">` のように差し替えてください。

写真は暖色寄り（露出やや高め・彩度控えめ）に現像すると、ページのトーンと揃います。
